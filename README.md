# A-Life Threat Alert

Standalone Project Zomboid Build 42 mod that warns when hostile Project A-Life NPCs are near the player. It does not require Viewpoint, Viewpoint Extended Support, or A-Life Stance Dots.

The A-Life warning distance is configurable from 5 to 100 tiles, with a default of 40. Warnings for careful NPCs can be enabled or disabled separately. When a threat is detected, an optional directional arrow points toward the nearest one relative to the player's facing direction. An optional firearm warning identifies nearby reportable NPCs carrying firearms and points the arrow toward the nearest carrier.

The mod can also warn about regular zombies behind the player. Balanced range is enabled by default and follows the vanilla perception distance: 3.5 tiles normally and 6.5 with Keen Hearing. Disable balanced range to set a custom distance from 5 to 100 tiles. The rear detection angle is adjustable from 30 to 360 degrees (180 degrees by default), and its directional arrow points toward the nearest detected zombie. Larger angles widen the detection area toward the sides and front. It also works when Project A-Life is not loaded; A-Life NPCs are excluded from the zombie count.
