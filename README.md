# A-Life Threat Alert

Standalone Project Zomboid Build 42 mod that warns when hostile Project A-Life NPCs are near the player. It does not require Viewpoint, Viewpoint Extended Support, or A-Life Stance Dots.

The warning distance is configurable in the mod options from 5 to 100 tiles, with a default of 40. Warnings for careful NPCs can be enabled or disabled separately. The mod is inactive if Project A-Life is not loaded.
